# Changelog v0.9

- Inicio se mantiene como hub de acceso rápido.
- Se reemplazan datos estáticos principales por un modelo dinámico de OC, asignaciones, lotes, inspecciones, NC y entregas.
- Producción mueve cantidades de forma controlada entre cuatro etapas.
- El paso a Limpios crea lotes inspeccionables.
- Inventario se calcula a partir de las asignaciones y movimientos reales de la demo.
- Inspecciones generan liberación pendiente o NC.
- Se incorpora retrabajo y reinspección.
- Entregas consumen lotes liberados y pueden cerrar automáticamente una OC.
- Se agrega esquema preliminar PostgreSQL/Supabase.
