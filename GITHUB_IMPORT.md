# Preparación para GitHub / Google AI Studio

1. Crea un repositorio nuevo, por ejemplo `campar-sgc`.
2. Sube **el contenido de esta carpeta**, no el ZIP como único archivo.
3. Confirma que `README_FIRST.md` quede en la raíz.
4. En Google AI Studio, importa el repositorio desde GitHub.
5. Como primer mensaje, pega el contenido de `AI_STUDIO_START_PROMPT.md` o pídele explícitamente que lo lea antes de editar.
6. Trabaja por versiones y conserva commits separados por cambio relevante.

La app web que puede ejecutarse directamente está en `app/index.html`.
